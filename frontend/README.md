# Frontend

Одностраничное приложение на Vue 3, TypeScript, Vite и Composition API.

## Ответственность

- форма: город, дата, формат, категория, бюджет, опционально длительность и язык;
- типизированный запрос к FastAPI без собственной логики ранжирования;
- показ до трёх карточек в порядке backend;
- конкретное объяснение для каждого подрядчика;
- заметная маркировка синтетических профилей;
- понятные состояния загрузки, ошибки и пустой выдачи.

## Планируемая структура

```text
frontend/
├── public/
├── src/
│   ├── api/             # типизированный HTTP-клиент
│   ├── assets/          # стили и ресурсы
│   ├── components/      # форма, карточки, сообщения
│   ├── composables/     # Composition API-сценарии
│   ├── pages/           # страницы
│   ├── router/          # маршрутизация
│   ├── stores/          # клиентское состояние
│   └── types/           # TypeScript-контракты API
└── tests/               # component- и e2e-тесты
```

## Основные компоненты

- `RecommendationForm.vue` — параметры заказа и валидация;
- `RecommendationResults.vue` — контейнер результата;
- `ContractorCard.vue` — данные и объяснение по подрядчику;
- `ResultNotice.vue` — причина неполной или пустой выдачи;
- `SyntheticBadge.vue` — отметка добавленного командой профиля;
- `useRecommendations.ts` — запрос и состояния `idle/loading/success/error`.

## Пользовательские состояния

| Статус backend | Отображение |
|---|---|
| `matched` | 1–3 карточки; при неполной выдаче — поясняющее сообщение. |
| `category_not_found` | В выбранном городе нет подрядчиков этой категории. |
| `no_eligible_candidates` | Кандидаты есть, но заняты или не подходят по условиям. |
| Ошибка API | Ошибка сети и повтор запроса без потери формы. |

Клиент не сортирует карточки самостоятельно: порядок является частью детерминированного ответа backend.

## Планируемая конфигурация

```dotenv
VITE_API_BASE_URL=http://localhost:8000
```

## Планируемый запуск

```bash
cd frontend
npm install
npm run dev
```

Команды станут доступны после добавления реализации. Адрес приложения: `http://localhost:5173`.

## Обязательные проверки

- обязательные поля нельзя пропустить;
- бюджет и длительность принимают только положительные значения;
- отображается не больше трёх карточек в порядке backend;
- объяснение и признак `synthetic` видны пользователю;
- три бизнес-исхода визуально различаются;
- сетевой сбой не выглядит как отсутствие подрядчиков;
- форма и результат доступны с клавиатуры и на мобильном экране.
