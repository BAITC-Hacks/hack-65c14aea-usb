# Событие — подбор event-подрядчиков

Vue 3 + TypeScript + Composition API (`script setup`), Vite, Tailwind CSS 4 и локальные компоненты shadcn-vue на Reka UI. Настройки генератора: `components.json`. [Официальная установка shadcn-vue](https://www.shadcn-vue.com/docs/installation/vite).

## Запуск

Требуется Node.js 22.12+ (рекомендуется актуальная LTS).

```bash
cd frontend
npm ci
cp .env.example .env
npm run dev
```

Приложение: http://localhost:5173. Бэкенд запускается по инструкции в ../backend/README.md. По умолчанию Vite проксирует `/api` на `http://127.0.0.1:8000`. Для другого порта измените `API_PROXY_TARGET`.

При размещении frontend и backend на разных доменах задайте `VITE_API_BASE_URL=https://api.example.com` до сборки и разрешите домен frontend в `FRONTEND_ORIGIN` бэкенда. В production с пустым `VITE_API_BASE_URL` веб-сервер должен проксировать `/api` к FastAPI; dev-прокси в сборку не входит.

## Данные и API

- `GET /api/v1/catalog/options` загружает города, категории, форматы и языки из реального каталога.
- `POST /api/v1/recommendations` получает рекомендации по форме.
- `GET /ready` показывает в шапке состояние каталога и Redis-кэша. Если кэш недоступен, подбор продолжает работать и интерфейс показывает деградированный режим.
- Сохранены порядок ответа сервера и ограничение до трёх карточек.
- В форме доступны город, дата, формат, категория, бюджет, опциональные язык и длительность.
- Дата ограничена контрактом датасета: 23.09.2026–31.12.2026.
- Показаны цена, объяснение, идентификатор и заметная отметка синтетического профиля.
- Интерактивная мини-карта синхронизирована с полем города и запускает реальный запрос рекомендаций.
- В интерфейсе есть готовые сценарии для плотной категории, редкой категории и результата без совпадений.
- Повтор запроса на второй дате доступен рядом с результатами и наглядно показывает влияние календаря.
- Различаются отсутствие категории, отсутствие подходящих кандидатов, загрузка и сетевые ошибки. Есть повтор запроса без потери формы, тайм-аут 15 секунд.
- Структурированные ошибки FastAPI (`detail[]`) преобразуются в понятное сообщение вместо общего сетевого сбоя.
- Фронтенд не подменяет данные статическими профилями из HTML. Количество и состав профилей зависят от проиндексированного backend-датасета.

## Проверки

```bash
npm run build
npm test
```

Тесты проверяют запросы, порядок карточек, синтетические профили, бизнес-исходы, повтор после сбоя и валидацию.

## Структура

- `src/api/client.ts` — HTTP-клиент.
- `src/types/api.ts` — контракты FastAPI.
- `src/composables/useRecommendations.ts` — состояние запроса и результата.
- `src/App.vue` — форма и состояния страницы.
- `src/components/ContractorCard.vue` — карточка результата.
- `src/components/KazakhstanMap.vue` — интерактивный выбор географии с отправкой запроса в backend.
- `src/components/ui/` — локальные компоненты shadcn-vue.
- `src/assets/main.css` — тема, адаптивная сетка и состояния.
