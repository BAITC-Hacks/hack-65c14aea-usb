# Smart Contractor Match — #79-lite

Хакатон-проект для объяснимого подбора event-подрядчиков в Казахстане.

## Структура

- [backend](backend/) — FastAPI, Elasticsearch, фильтрация, ранжирование и объяснения.
- [frontend](frontend/) — Vue 3, TypeScript и Composition API.

Подробности архитектуры и будущего запуска находятся в README каждой части.

## Основной сценарий

Пользователь задаёт город, дату, формат мероприятия, категорию подрядчика и бюджет, опционально — длительность и язык. Сервис возвращает до трёх доступных подрядчиков с конкретными объяснениями либо явно сообщает одну из причин пустой выдачи:

1. в городе нет подрядчиков выбранной категории;
2. подрядчики есть, но все заняты или не проходят обязательные условия.

Одинаковый запрос должен всегда возвращать одинаковый порядок карточек.
